# SYN†H

Локальный веб-синтезатор в эстетике witch house: два голоса, орган, низкий синтетический хор, барабанный секвенсор и четыре эффекта. Шрифты и фон находятся в проекте. Сборка, установка пакетов и ChatGPT Sites для запуска не нужны.

## Структура проекта

```text
synth/
├── index.html
├── README.md
├── fonts/
│   ├── Manrope-Bold.ttf
│   ├── Manrope-ExtraBold.ttf
│   └── ManufacturingConsent-Regular.ttf
├── images/
│   └── background.jpg
├── javascripts/
│   └── script.js
└── stylesheets/
    ├── style.css
    ├── reset.css
    └── layout.css
```

`style.css` подключает `reset.css` и задаёт оформление инструмента, шрифты и анимацию фона. `layout.css` содержит адаптацию под разные размеры экрана и настройку уменьшения движения. `script.js` содержит звуковой граф, секвенсор и управление.

## Запуск в VS Code

Откройте всю папку `synth` через File → Open Folder. Откройте корневой `index.html` в браузере или через Live Server, если он уже установлен.

Также можно запустить из терминала проекта `python3 -m http.server 8080` и открыть `http://127.0.0.1:8080/`.

## Управление

- PLAY / STOP запускают и останавливают восьмишаговый рисунок. Стартовый темп — 88 BPM.
- VOICE 01: бас с выбором волн и трубный орган. VOICE 02: перегруженный верх, воздушный слой и низкий хор. VOLUME и PAN каждого голоса управляют всеми его слоями.
- SINE / TRIANGLE / SAW / SQUARE выбирают волну основного синта.
- C / D / E♭ / G включают ноты в минорном рисунке. A / S / D / F играют первый голос, J / K / L / ; — второй. Пробел запускает и останавливает секвенсор, когда фокус не в поле ввода.
- DRUM SEQUENCER: восемь шагов для KICK, SNARE и HAT. Ячейки включают удары; названия строк позволяют прослушать звук.
- DISTORTION, FILTER, DELAY и REVERB управляют общей цепочкой эффектов. MASTER — общей громкостью.
- GLITCH ON / OFF управляет глич-фоном. Всплески длятся 1,6 секунды с паузами 6–12 секунд. Уменьшение движения в системе учитывается.
- При переключении на другую вкладку секвенсор останавливается. Хвосты эффектов затихают естественно.

## Структура звука

Два синтезатора имеют отдельные каналы громкости и стереопанорамы; барабаны используют третий канал. Основные синты и барабаны идут в distortion → filter, затем прямой сигнал складывается с delay. Орган, хор и воздушный слой имеют отдельные чистые пути с громкостью и панорамой соответствующего голоса. Общая шина идёт в reverb и master, затем в компрессор, мягкое ограничение амплитуды и стереовыход.

Все звуки создаются Web Audio API. Внешние сэмплы и библиотеки не требуются. Ссылки на GitHub-репозиторий и скринкаст добавляются после их создания.
