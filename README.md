# SYN†H

Веб-инструмент в эстетике witch house: два независимых монофонических синтезатора, драм-машина и общая цепочка из четырёх эффектов. Дизайн — по предоставленному макету, шрифты Manrope Bold / ExtraBold и Manufacturing Consent поставляются локально.

## Запуск

Откройте `index.html` в браузере или запустите из папки проекта `python3 -m http.server 8080` и перейдите на `http://localhost:8080`.

## Управление

- PLAY / STOP запускают и останавливают общий восьмишаговый рисунок. BPM: 45–180.
- VOICE 01 — бас, VOICE 02 — верхний голос. У каждого свой выбор SINE / TRIANGLE / SAW / SQUARE, громкость и стереопанорама.
- C / D / E / G включают и выключают ноты в мелодическом рисунке. При включении нота звучит отдельно. Можно выключить все ноты одного голоса.
- A / S / D / F играют первый голос, J / K / L / ; — второй. Пробел запускает и останавливает секвенсор, когда фокус не находится на элементе управления.
- В DRUM SEQUENCER каждая строка содержит восемь восьмых долей. Клик по ячейке включает удар; клик по KICK / SNARE / HAT прослушивает звук.
- DISTORTION — насыщение, FILTER — простой low-pass, DELAY — синхронное эхо, REVERB — пространственный хвост. MASTER управляет общей громкостью.
- GLITCH ON / OFF отключает анимацию фона. Системная настройка уменьшения движения учитывается автоматически.
- При переходе на другую вкладку секвенсор останавливается. STOP останавливает голоса и барабаны; хвосты эффектов затихают естественно.

## Структура инструмента

```text
VOICE 01: oscillator → envelope → volume → pan ─┐
VOICE 02: oscillator → envelope → volume → pan ─┼→ mix → distortion → filter
DRUMS: kick / snare / hat → drum volume → pan ─┘                        │
                                                  dry + delay return ─┤
                                                                      ↓
                                                         reverb send + dry
                                                                      ↓
                                                           master → limiter → stereo out
```

Два голоса имеют отдельные каналы. Барабаны используют третий канал с центральной панорамой. Эффекты общие, delay с обратной связью и reverb работают параллельно с прямым сигналом. Звуки создаются Web Audio API; внешние сэмплы и библиотеки не требуются.

Имена интерфейса соответствуют блокам: VOICE 01 / VOICE 02, DRUM SEQUENCER, EFFECTS, MASTER. В каждом голосе сначала выбирается форма волны, затем набор нот, затем громкость и панорама.

## Файлы

- `index.html` — оболочка инструмента.
- `stylesheets/synth.css` — интерфейс и глич-анимация.
- `javascripts/synth.js` — звуковой граф, секвенсор и управление.
- `images/background.jpg` — предоставленный фон; `*-reference.*` — исходные макеты.
- `fonts/` — локальные шрифты.

## Демонстрация

Запустите PLAY, переключите VOICE 01 на SAW, VOICE 02 на TRIANGLE, измените панораму, добавьте удары HAT, поднимите DELAY и REVERB, затем нажмите STOP. Для сдачи запишите экран со звуком инструмента и загрузите запись на выбранную площадку.
